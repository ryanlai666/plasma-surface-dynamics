# Public bulk geometry

`9005018.cif` is the alpha-quartz structure of Kihara (1990), measured at 398 K, downloaded from [COD 9005018](https://www.crystallography.net/cod/9005018.html); [source CIF](https://www.crystallography.net/cod/9005018.cif), [paper DOI](https://doi.org/10.1127/ejm/2/1/0063). COD data are public-domain/CC0.

It supplies a bulk lattice for generated (001) screening slabs, not a published surface reaction path. The nitride bulk source remains at `docs/mace_results/2102550.cif`. Calculation summaries store exact CIF SHA-256 checksums.
